# Poco F7 / Android 16 実機チェック

小さなテストフォルダと復元用の別フォルダを使ってください。以下は確認手順であり、実施済みを意味しません。

- [ ] Release APKがインストールでき、画面がステータスバーやナビゲーションバーに隠れない
- [ ] Google Cloud登録後、意図したアカウントへ接続できる
- [ ] フォルダ許可が再起動後も保持される
- [ ] Wi-Fi・充電中に手動バックアップが成功する
- [ ] Wi-Fi OFF・モバイル許可OFFでは送信待ちになり、送信しない
- [ ] モバイル許可ONで携帯回線からバックアップできる
- [ ] Wi-Fiのみで送信中にWi-Fiを切ると携帯回線に移行しない
- [ ] 携帯回線で送信中にモバイル許可をOFFにすると処理が中止される
- [ ] 充電中のみONで充電器を抜くと中止または待機し、条件が戻ると再試行できる
- [ ] キャンセル通知ボタンとアプリの中止ボタンが機能する
- [ ] 読み取り権限を取り消したフォルダがある場合に失敗を表示し、古い世代が残る
- [ ] バックアップしたZIPをダウンロードし、正しいパスワードで別フォルダへ復元できる
- [ ] 元ファイルと復元ファイルの内容・SHA-256が一致する（日本語名、空ファイル、空フォルダ、動画も含める）
- [ ] 間違ったパスワードで復元しても平文ファイルが作られない
- [ ] 8回成功後、同じインストールの最新7件が残り、古い1件のみゴミ箱に移動する
- [ ] Driveの別ファイルや別インストールのバックアップが整理されない
- [ ] 画面OFF・端末再起動後にも定期実行される（正確な時刻は保証しない）
- [ ] 通信切断・容量不足・Google許可取消で失敗が表示され、古いバックアップが残る
- [ ] 同じ署名鍵の新しいAPKを上書きインストールでき、設定が残る

署名、Googleのアカウント登録、実際のネットワーク・端末省電力設定に依存するため、CIだけではこれらを保証できません。
